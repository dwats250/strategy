## 1. What this file is

The external register of SHA-256 hashes for the documents Phase 0 created.

**No document records its own hash.** That is self-referential and unsatisfiable: writing a
file's hash into that file changes the hash. Hashes are therefore recorded **here**, in a
separate file, following the precedent already set by `../INSTALLATION_RECORD.md`, which
records the hashes of other documents and never its own.

## 3. This register's own attestation

**This file records no hash of its own.** It is attested instead by **the Phase 0 commit SHA**
— the Dustin-merged commit that introduced this file. That commit's tree fixes this file's
blob, so the commit SHA is a stronger and non-circular attestation than a self-reference could
ever be.

To verify this register's content as merged:

```sh
git log --oneline -- audits/cuttingboard-engine-strategy-audit/closure/HASHES-2026-07-27.md
git rev-parse HEAD:audits/cuttingboard-engine-strategy-audit/closure/HASHES-2026-07-27.md
```

No follow-up edit inserting a self-referential SHA may be made to this file. Such an edit
would change the blob it purported to attest.

## 5. Scope limit

This register is **not an audit authority.** It records hashes and their verification result.
It cannot alter a gate formula, threshold, classification, variant, safeguard, or review rule,
and it authorizes no work. It reads, references, and mutates nothing in
`dwats250/cuttingboard`.
